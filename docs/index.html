🌍 Earth Trip Visualizer

A lightweight, in-browser preview of the desktop app. Type two real cities and watch a simplified fly-through animate right here — no install required. For the full-resolution, downloadable Instagram Stories MP4, run the real desktop app.

This is a preview, not the production tool. It renders a scaled-down globe entirely in your browser (no video is produced or downloadable), uses the same NASA Blue Marble texture as the desktop app instead of live satellite zoom-in, and uses emoji for flags/transport icons instead of fetched artwork. City search is real — it geocodes through the same public OpenStreetMap service the desktop app uses.
Source texture: NASA Visible Earth Blue Marble (public domain) · Geocoding: OpenStreetMap Nominatim
